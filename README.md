> Interactive, cyber-aesthetic developer portfolio engineered with **Next.js 16**, **React 19**, and **Tailwind CSS v4**. Features a Solo Leveling dynamic background, interactive Web Audio arcade games, and fully functional screen-time wellness tools.

---

## 🌟 Featured Projects

### 1.  Seahorse Flight: Flappy Frost (Arcade Game)
- **Engine**: Pure HTML5 `<canvas>` + TypeScript.
- **Audio**: Custom multi-voice Web Audio API synthesizer (wing flaps, ice crystal rings, game over chords).
- **Features**: Real-time collision detection, particle exhaust trails, progressive velocity acceleration, dynamic combo score system, and Deep Freeze high-score tracking.

### 2. TimeGuard (Smart Screen Time & Digital Wellness System)
- **Features**:
  - **Live Usage Tracking & Lockout**: Real-time app usage tracking with 100% lockout shields and emergency override tokens.
  - **App Limit Customizer**: Interactive sliders for daily limits (TikTok, Facebook, Mobile Legends, YouTube, Instagram).
  - **Focus Mode**: Preset focus sessions (25m, 45m, 60m, 90m) with live SVG countdown timer and celebration effects.
  - **Digital Wellness Analytics**: Category breakdown, daily streaks, habits checklist, and screen-time reports.
  - **Companion Native Architecture**: Includes Android Companion architecture (`UsageStatsManager`, `AccessibilityService`, `WorkManager`).

## 🚀 Getting Started

### Prerequisites
- Node.js `18.x` or higher
- npm, yarn, or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/jstnexc/Just-in-Portfolio.git

# Navigate into the project directory
cd Just-in-Portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build

```bash
npm run build
npm start
```
